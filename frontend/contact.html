Questions fréquentes

Comment trouver un mentor ? +
Créez votre profil, renseignez vos lacunes et cliquez sur "Trouver un mentor". Notre algorithme vous proposera automatiquement les meilleurs matches selon vos besoins.
MeetSkills est-il gratuit ? +
Oui, MeetSkills est totalement gratuit pour tous les étudiants béninois. Pas de frais cachés.
Comment se déroulent les sessions de mentorat ? +
Les sessions se déroulent exclusivement en ligne via des outils comme Google Meet, Zoom ou WhatsApp. Vous convenez des détails directement via la messagerie intégrée.
Mon université n'est pas reconnue, que faire ? +
Contactez-nous via le formulaire ci-dessus en sélectionnant "Suggestion" et indiquez le nom de votre université. Nous l'ajouterons rapidement.
